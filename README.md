# RGM Mobile (Raycasting Game Maker Mobile)
Мобильный порт Raycasting Game Maker'а. Перенесены не все функции, однако проект активно развивается.

### Что уже умеет конструктор 
* **Экспорт в APK**.
* Система кастомных ассетов
* Сетка карты
* Поддержка нескольких уровней
* Кастомизации главного меню
* Система врагов, аптечек, патронов и оружия

### Чего он ещё НЕ умеет (но будет уметь в будущем)
* Оружие ближнего боя
* Кастомные шрифты
* Кастомный дизайн HUD-панели

### Управление
* Walls -> Import wall texture -> тап по сетке для рисования. Если попытаться свайпнуть, будет перемещение по сетке. Для рисования стенами только тапы. Выбирайте, какой стеной рисовать, в левой панели, категория **Walls**.
* Sprites -> Import sprite -> тап по сетке для рисования. Выбрать спрайт в левой панели в категории **Sprites**.
* Enemies -> Create Enemy. Откроется **Редактор врагов**. Здесь можно создать врага, вам нужно просто импортировать кадры врагов (**бездействие, ходьба, смерть, атака**).
* Doors -> Import door texture, у вас появится дверь. Дверь можно поставить на сетке, тогда при касании двери во время геймплея она автоматически откроется. Если ее никто не трогает, она закроется через 5с.
* InGameItems -> Gun. Откроется **Редактор оружия**. Выбирайте 3 кадра для выстрела (они будут использоваться во время выстрела) и 3 кадра перезарядки (это будет каждый раз при выстреле). Также нужен Ground кадр, это текстура оружия которое лежит на земле и его можно подобрать.
* Двойной тап по клетке с ассетов = удалить ассет с клетки. Ассет не удаляется из левой панели, он удаляется в текущей клетке.
* Если вам надо полностью удалить любой тип ассетов с сетки, Walls -> **Delete all walls**, либо Sprites -> **Delete all sprites**.
