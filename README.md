# RGM Mobile (Raycasting Game Maker Mobile)
Мобильный порт Raycasting Game Maker'а. Перенесены не все функции, однако проект активно развивается.

### Что уже умеет конструктор 
* **Экспорт в APK**.
* Система кастомных ассетов
* Сетка карты
* Поддержка нескольких уровней
* Кастомизации главного меню
* Система врагов, аптечек, патронов и оружия

### Чего он ещё НЕ умеет (но будет уметь в будущем)
* Враги ближнего боя
* Оружие ближнего боя
* Кастомные шрифты
* Кастомный дизайн HUD-панели

### Информация о движке
* Переписан с нуля на веб-технологиях
* Конвертирован в APK
* Распространяется под свободной лицензией (**MIT**)
* Активно развивается

**Примечание**: после того, как все функции оригинала будут добавлены, проект станет получать новый контент основываясь на личных предпочтениях автора, и со временем перерастет в самостоятельный проект.
